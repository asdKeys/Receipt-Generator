# Receipt Generator

## About

This is a receipt generator. It will generate a variety of random receipts.

## How to Run

Looking at the screenshots nearly as cool as trying it out yourself so just go to https://www.onlinegdb.com/online_python_compiler#, then scroll up and double click the file called "main.py". Then, copy and paste that code into the python compiler. To run the code properly, you must click the drop-down arrow next to the run button and then press "Run with display screen(beta)" as demonstrated in the screenshot below. If the display screen takes more than 20 seconds to connect or something goes wrong, just refresh and try again.

![How to Run](Screenshot%202026-09-07%20143743.png)

## What My Calendar Does

- Plans Events
- Plans Classes For Homeschool
- Is very flexible because you can make the title and description whatever you want
- (Even the time can be whatever you want it doesn't even have to be a time!)
